# Brew Calendar

Brew Calendar is a personal Windows desktop application that helps manage homebrewing schedules using BeerSmith 4.

The application provides a calendar interface for scheduling brew days, dry-hop additions, and packaging dates.

## Google Calendar Integration

Brew Calendar can synchronize brewing events to a dedicated Google Calendar using Google's Calendar API.

Google Calendar access is used solely to create, update, and remove brewing-related calendar events.

## Privacy

Brew Calendar is a personal-use application. It does not operate a developer-hosted server or sell user information.
